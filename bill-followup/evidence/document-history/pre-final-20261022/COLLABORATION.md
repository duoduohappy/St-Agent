# 协作原始记录与导出缺口

正式协作起点为用户要求完整读取题面并“目前先分析，暂不编码”的消息。正式协作前问候及其他项目历史不在范围。

## 已实际核实的能力

本会话本地JSONL含用户消息、助手可见回复、工具调用和工具返回；已确认其中可找到完整题面读取调用与返回。工具目录没有本会话完整原始导出接口。官方文档检索也未建立“当前环境可完整导出”的结论，不能以文档搜索代替实测。

核查时访问的官方页面：[OpenAI Docs：故障排查](https://learn.chatgpt.com/docs/reference/troubleshooting)。本项目导出能力结论来自本地JSONL和可用工具实测，而非该页面保证。

`tools/export_collaboration.py`只读指定会话文件，从正式协作起点选择可见记录，**直接复制每条选中JSONL的原始字节**，不重写或整理工具返回。`*-manifest.json`包含源快照大小/哈希、导出哈希、逐行来源索引、未配对调用、排除类别和缺口。`*-visible-original.jsonl`是可提供的原始记录，不能称为平台完整导出。

每次导出新快照，之前快照保留。manifest中的`unpaired_call_ids_at_snapshot`会包括导出当时尚未完成的当前工具调用；后续快照可以补入已刷盘的结果，但最终导出本身及最后回复仍可能未在最后快照中。

## 明确的缺口和排除

1. 平台未写盘、截断或未暴露的嵌套工具结果无法恢复；保留源文件实际提供的可见内容。
2. 当前仍在执行的调用、最后导出后的回复和工具结果可能缺失，截止时间以manifest为准。
3. 隐藏推理、系统/开发者指令、重复事件镜像、正式起点前历史不导出；题面不要求隐藏思维链。
4. 没有子Agent或其他聊天委托，无相应子任务记录。没有将摘要冒充这些记录。
5. 目前未验证UI导出能否提供更完整的记录，不声称完整平台导出已经完成。
6. 本地记录包含电脑重启后继续消息。恢复后沿用原项目与数据库；路径现为D盘，之前C盘工作目录在运行输出中解析为D盘。旧输出保持原样。

## 可复现导出

将实际源会话路径传给脚本：

```powershell
python tools/export_collaboration.py <本会话JSONL路径>
```

只允许命中正式协作起点才导出，防止意外复制其他聊天。脚本不读取auth.json、凭据或其他会话。交付不包含整个Codex目录。

## 索引与关键判断（整理说明，不是原始记录）

- 不接大模型，以确定性规则满足状态与恢复要求。
- 无序对规范化＋数据库唯一约束，避免重放与三笔关联误合并。
- 事实、结论、提醒额度、发送结果、开关分别保存。
- 原始到账缺ID或冲突时采取待核对，不猜测去重。
- 使用模拟通道事务生效点，明确关闭与发送先后，真实并发测试验证。
- 未知不能计成功，也不能盲目重发；用操作ID核对。
- 失败修复原样保留：重试模拟设置未复位、验收入口路径错误、终端中文编码修正，见TESTING.md及原始工具记录。

测试进程原始输入输出位于每次验收的invocation/stdout/stderr及每个场景证据中；核心CLI实际调用的完整参数与原始stdout/stderr位于stage-one目录。它们是执行证据，不替代会话原始JSONL。
